Bird names
Handwritten names on the collage. Nested sets each name along the bird's own back or belly, so it reads as part of the drawing; Below parks it underneath. Off keeps the collage a picture — hover a bird to name it.

How long a newly-arrived bird is drawn in flight instead of perched. Never keeps the whole flock perched.
