All illustrations here are **CC BY-NC-SA 4.0** — attribution required,
non-commercial use only, share-alike. Per-image author + license live in
`data/image_credits.json` and show on each species' detail page.

- **`<sci-name-slug>_perched.png` / `_flight.png`** (e.g.
  `corvus-corax_perched.png`) — from the **AvianVisitors** project by
  **Teddy Warner** (https://github.com/Twarner491/AvianVisitors), branch
  `avian-visitors`, `avian/assets/illustrations/`.
  `_illustration_sources.json` records the repo-slug → installed-slug mapping
  used at install time.
- **eBird speciesCode-named files shipped with this branch** (e.g.
  `norgos_perched.png`) — created by **Breakerfallen**
  (https://github.com/Breakerfallen).
- **Anything you add yourself** — via the ⚙ settings uploader or
  `build_images.py` — is credited to you: set `owner_name` in `config.json`
  before uploading.
