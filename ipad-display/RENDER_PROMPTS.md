# Birds still needing art — render prompts

The 26 needed species (Kathryn's or Melissa's) still showing as silhouettes.
Each block below is a complete, ready-to-paste prompt for a **perched** kachō-e
illustration. Copy one block, paste it into ChatGPT, download the PNG, then
upload it to that species' **Perched** slot in the app (**⚙ → Bird images**).
Ask for a square PNG with a transparent background; if a detail is wrong, correct
it in plain words and regenerate. The board handles sizing (by body length,
listed per bird) — you just fill the frame.
